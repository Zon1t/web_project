# docs/sql — 슥밥 DB 스크립트

Oracle XE 11g 기준. 테이블은 JPA가 만들지 않으므로(`ddl-auto: none`) 이 스크립트로 직접 만든다.

## 실행 순서

| 순서 | 파일 | 내용 | 언제 |
| --- | --- | --- | --- |
| (0) | `00_drop.sql` | 테이블·시퀀스 전체 삭제 | 처음부터 다시 만들 때만 |
| 1 | `01_ddl.sql` | 테이블 11개, 제약조건, 인덱스 5개 | 필수 |
| 2 | `02_sequence.sql` | 시퀀스 10개 | 필수 |
| 3 | `03_init_data.sql` | 리뷰 태그 13건, 구내식당 1건 | 필수 |
| 4 | `04_dummy_data.sql` | 테스트용 회원·식당·리뷰·식사팟·대화 등 | 개발 PC에서만 |

## SQL Developer에서 실행하는 법

1. 본인 계정(`application-local.yml`과 같은 계정)으로 접속한다.
2. 파일을 열고 **스크립트 실행(F5)** 을 누른다. (Ctrl+Enter는 한 문장만 실행하므로 쓰지 않는다)
3. 위 순서대로 파일마다 반복한다.
4. 확인: `SELECT TABLE_NAME FROM USER_TABLES ORDER BY 1;` → 11개가 나오면 성공.

## 더미데이터 테스트 계정

- `user01` ~ `user05`, 비밀번호는 모두 `04_dummy_data.sql` 맨 위 주석에 적힌 값이다.
- 날짜는 실행한 날 기준이다. 다음 날이 되면 "오늘 식사팟"이 사라지므로 `00` → `04` 순서로 다시 실행하면 된다.
- 기대 결과(랭킹 순서, 오늘 식사팟 수 등)는 `04_dummy_data.sql` 맨 위 주석에 있다.

## 수정 규칙

- 테이블·컬럼 변경은 팀 합의 후 이 폴더의 스크립트를 고친다. (엔티티로 테이블을 만들지 않는다)
- `03_init_data.sql`의 구내식당 `MAP_URL`·좌표는 임시값이다. 실제 값으로 교체 필요.
